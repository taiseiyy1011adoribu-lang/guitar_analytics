# guitar_analytics

音源（wav など）からギターのタブ譜をテキストで作る最小版です。

1. [Spotify Basic Pitch](https://github.com/spotify/basic-pitch) で音高・開始・終了のノート列を取り出す
2. 倍音を誤検出した弱い音を取り除き、ほぼ同時に始まる音を和音としてまとめる
3. librosa のビート検出でテンポと拍の位置を推定し、各音を 16 分音符のグリッドにそろえる
4. 動的計画法（ビタビ）で、手の移動が少なく弾きやすい弦とフレットを選ぶ（下の「弦・フレット割り当て」）
5. 小節線と音価の記号付きの ASCII タブ譜として出力する

## Windows アプリとして使う（コマンド操作なし）

1. GitHub の [Releases](../../releases) から最新の `GuitarTab-Setup-<版>.exe` をダウンロードする
2. ダブルクリックしてインストールする（管理者の権限は要りません。「PC が保護されました」と出たら「詳細情報」→「実行」）
3. スタートメニューかデスクトップの「ギタータブ譜メーカー」から起動すると、ブラウザで画面が開く。黒い画面を閉じると終了する

新しい版も同じ手順で上から入れ直せます。最初の解析だけ、準備のため 20 秒ほど余計にかかります。

### 新しい版を公開する

GitHub の「Actions」→「Windows アプリを作る」→「Run workflow」で版番号（例 `0.2.0`）を入れて実行すると、
Windows 上で exe とインストーラーが作られ、サンプル音源で解析できるか確かめてから Releases に公開されます（20 分ほど）。
`v0.2.0` のようなタグを付けても同じです。プルリクエストでも毎回ビルドだけ行い、できた setup.exe は実行結果の Artifacts から試せます。

- 入口は `guitar_analytics/app.py`（`python -m guitar_analytics.app` でも同じ動きをします）
- exe の中身は `packaging/guitar_analytics.spec`（PyInstaller）、インストーラーは `packaging/installer.iss`（Inno Setup）
- exe には TensorFlow を入れず、Basic Pitch 同梱の ONNX 版モデルを onnxruntime で動かしています（`requirements-app.txt`）。
  `samples/sample.wav` のタブ譜は TensorFlow 版と同じになることを確かめています

## セットアップ

Python 3.10 か 3.11 が必要です（Basic Pitch の都合）。

```sh
python3.11 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

## 使い方

```sh
python -m guitar_analytics input.wav             # 標準出力にタブ譜
python -m guitar_analytics input.wav -o tab.txt  # ファイルに書き出す
python -m guitar_analytics input.wav --notes     # 検出したノートも表示
python -m guitar_analytics input.wav --bpm 96    # テンポを指定（推定が倍や半分になったとき）
python -m guitar_analytics input.wav --beats-per-bar 3  # 3 拍子
python -m guitar_analytics input.wav --no-rhythm # リズムなしで弾く順番だけ
```

タブ譜の各段の上の行が音価です（w=全音符、h=2分、q=4分、e=8分、s=16分、`.` は付点）。
1 文字分の幅が 16 分音符 1 つに当たり、`|` が小節線です。

リズムについての制限:

- 1 小節目の頭は「最初の音にいちばん近い拍」としています。弱起（アウフタクト）の曲では小節線がずれます
- テンポが途中で変わる曲には対応していません
- 小節線をまたぐ音は小節の終わりで切って表示します（タイは付けません）

### 画面で見る

```sh
python -m guitar_analytics.web          # http://127.0.0.1:8000/ がブラウザで開く
python -m guitar_analytics.web --port 8080 --no-browser
```

音声ファイルをドロップすると、時間に沿ったタブ譜と検出した音のピアノロールが表示されます。
再生するとカーソルが動き、クリックした位置から再生できます。「聞く音」で元の音源と検出した音（簡単な合成音）を切り替えられるので、取りこぼしや誤検出を耳で確かめられます。
しきい値は「解析の設定」から変えて解析し直せます。追加のライブラリは要りません（Python 標準のサーバーで動きます）。

#### キーとスケール

解析が終わると「キーとスケール」の欄に、次のものが出ます（`guitar_analytics/theory.py`）。

- **キーの推定**: 音の長さと強さで重みを付けた 12 音の分布を Krumhansl-Kessler のプロファイルと比べ、24 のキーから選びます。曲の最初と最後のベース音も少し考慮し、平行調（C メジャーと A マイナーなど）で迷うときはその旨を表示します
- **スケールの候補**: メジャー、マイナー、ペンタトニック、ブルース、各モード、ハーモニックマイナーを 12 のルートで比べ、曲の音がどれだけ含まれるかで順位を付けます
- **指板**: 選んだスケールの音を指板全体に表示します（ルート・スケール音・曲に出てきたスケール外の音を色分け、音名と度数の切り替え）。曲で弾いた位置は輪で示し、再生中は鳴っている位置と、そのときのコードの構成音を強調します
- **コード進行（推定）**: 0.5 秒ごとにコードの型と照合し、ビタビでならしています。クリックでその位置へ移動します。単音だけの音源では外れやすいです
- **ソロで使えるスケール**: なぜ合うかと弾き方のコツ、6 弦ルートのポジション付き。コードごとにも「そのコードの上で使えるスケール」を出します
- **アレンジのアイデア**: 出てきたコードごとに、平行調の代理コード、セブンス化、セカンダリードミナント、裏コードなどを提案します

`pip install -e .` すると `guitar-tab input.wav` でも動きます。
主なオプションは `python -m guitar_analytics -h` を見てください。

## サンプル

`samples/sample.wav` は `scripts/make_sample.py` で合成した音（120 BPM で E3 から A4 までの 4 分音符 8 つと、付点 2 分音符の開放 E メジャー和音）です。
出力は `samples/sample_tab.txt` にあります。

```

  q       q       q       q        q       q       q       q
e|--------------------------------|--------0-------3-------5-------|
B|------------------------0-------|3-------------------------------|
G|--------0-------2---------------|--------------------------------|
D|2-------------------------------|--------------------------------|
A|--------------------------------|--------------------------------|
E|--------------------------------|--------------------------------|

  h.
e|--------------------------------|
B|0-------------------------------|
G|1-------------------------------|
D|--------------------------------|
A|2-------------------------------|
```

単音はすべて正しく取れています。和音は 6 音のうち 4 音で、4 弦 2 フレット（E3）は 6 弦開放の倍音として、1 弦開放（E4）は Basic Pitch が検出しなかったため抜けています。

## 弦・フレット割り当て（`guitar_analytics/fingering.py`）

同時に鳴る MIDI ノートのイベント列から、各ノートを弾く弦とフレットを
動的計画法（ビタビ）で選びます。

- 状態: 押さえ方（同時発音は必ず別弦、指 4 本以内、セーハ可）と手のポジション（人差し指のフレット、届く範囲は 4 フレット）
- 状態コスト: ストレッチ幅、高いポジション、開放弦ボーナス、和音の間の弾かない弦
- 遷移コスト: 手のポジション移動量、5 フレットを超えるシフト、単音での弦の飛び越し
- 重みは `CostWeights` で調整できます

```python
from guitar_analytics.fingering import assign_frets
assign_frets([[64], [62], [48, 52, 55, 60, 64]])
# => [[(1, 0)], [(2, 3)], [(5, 3), (4, 2), (3, 0), (2, 1), (1, 0)]]
```

単純ルール（毎回いちばん低いフレット）との比較: `PYTHONPATH=. python examples/compare_fingering.py`

以前の単純ルールは `guitar_analytics/simple_fingering.py` に残してあります。
